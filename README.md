# 🚲 따릉이 이용 패턴 대시보드

> **질문**: 시간대·요일·연령대·대여소별로 따릉이 이용 패턴은 어떻게 다른가? 날씨나 계절의 영향은?

Streamlit 기반 대시보드입니다. 2025년 7월 ~ 2026년 6월 서울시 따릉이 시간대별 이용정보를 시간/요일/연령대/대여소 단위로 재집계해 필터와 함께 탐색할 수 있습니다. 앱은 이 12개월 전체를 기준으로 필터 옵션을 제공합니다. 원본 기간이 달라지면 `prepare_data.py`와 `app.py`의 기준일(`BASE_DATE`)·월 목록(`DATA_MONTHS`)을 함께 변경해야 합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `prepare_data.py` | 원본 CSV(202507~202606 대상 12개) + 대여소 마스터를 읽어 연도별 parquet 생성 (1회성) |
| `app.py` | Streamlit 대시보드 |
| `rental_agg_YYYYMM.parquet` (12개) | ETL 결과(월별 분할, 각 약 10~13MB, 앱과 같은 폴더에서 읽음) |
| `borrow.xlsx` | 대여소 자치구/좌표/이름 (원본에서 복사, 앱과 같은 폴더) |
| `seoul_districts.geojson` | 서울 25개 자치구 경계 (지도용, WGS84, 앱과 같은 폴더) |

## 실행

```powershell
python -m pip install -r requirements.txt

# 1) 최초 1회: 데이터 집계 (원본이 Downloads에 있어야 함)
python prepare_data.py

# 2) 대시보드 실행
streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 `http://localhost:8501`로 접속하세요.

## 대시보드 기능

**사이드바 필터**: 기간 선택 방식(달력 선택 / 월별 선택 중 택 1) — 달력 선택은 시작~종료일 지정, 월별 선택은 `25.07`~`26.06` 필 버튼 복수선택 / 요일(전체/평일/주말), 연령대(클릭형 필 버튼·10대→70대 이상 순), 시간대(0~23 슬라이더), 계절(봄·여름·가을·겨울 필 버튼), 대여소 순위 개수

**KPI** (필터 연동): 총 이용건수, 일평균 이용건수, 평균 이동거리, 평균 이용시간, 이용 대여소 수

**차트**
1. 시간대별 이용 건수 (바)
2. 연령대별 이용 비중 (도넛 · 10대→70대 이상 순으로 고정, 기타는 마지막)
3. 요일 × 시간대 히트맵
4. 서울 25개 자치구 경계 choropleth 지도(서울 전체가 한 화면에 고정, 마우스 오버 시 구·이용건수·대여소 수·평균 이용시간 표시) + 인기 대여소 Top N (가로 바)
   - **구역을 클릭하면** 서울 지도 자리에 해당 구의 상세 지도가 그대로 덮어씌워집니다. 연한 구역 면은 점들 뒤에 깔리고, **구 경계선은 대여소 점들 위에 한 번 더 겹쳐 그려져** 지도와 점이 함께 보입니다. **구 이름 라벨은 지도 위 전용 공간(상단 마진)에 고정 표시됩니다** (지도 좌표에 얹지 않아 잘리거나 점과 겹치지 않음). 대여소 위치(점 크기=이용건수, 색=거치대수)와 이용건수/일평균, 대여소 수, 평균 거치대수, 대여소 밀도(개/km²), 이용 상위 **5개** 대여소가 아래에 표시됩니다. 상위 대여소 표의 거치대수와 평균 이용시간 사이에는 **시간대별 평균 즉시 탑승 가능 대수(추정)**가 표시됩니다(실시간 재고가 없어 `거치대수 − 해당 시간대 일평균 대여건수`, 0 미만 0으로 근사). 지도 **바로 아래**에 '구 직접 선택'(가나다 순)을 두어 상세 보기 중에도 다른 구로 바로 전환할 수 있고, 그 아래 '전체 보기' 버튼으로 닫습니다(두 컨트롤 모두 지도 밑에 표시).
   - **전체 지도**에서만 마우스 호버 시 해당 구역이 살짝 확대되고 테두리가 강조되며, 동시에 기존 툴팁(구·이용건수·대여소 수·평균 이용시간)도 표시됩니다. 상세 지도에는 호버 확대를 적용하지 않습니다. Plotly 선택 이벤트가 간혹 발생하지 않는 경우에 대비해, 클릭 좌표가 속한 구 polygon을 직접 찾아 `plotly_selected`를 발생시키는 보강 스크립트도 함께 넣었습니다.
5. 계절별 / 월별 이용량

**확장**: 사이드바 아래 `날씨 데이터로 확장하기`에서 `날짜, 기온, 강수량` 컬럼을 가진 CSV를 올리면 일별 이용량과 기온의 산점도·상관계수를 볼 수 있습니다.

## 데이터 처리 참고

- 원본 CSV는 **cp949** 인코딩이며, 필요한 컬럼만 `usecols`로 읽습니다.
- 집계 키: `날짜, 연월, 시간, 요일, 주말여부, 월, 계절, 연령대, 대여소번호, 대여소명`
- 연령대 라벨은 `~10대 → 10대`, `70대이상 → 70대 이상`으로 통일하고 10대부터 70대 이상 순으로 정렬합니다.
- 이용건수는 합계, 이동거리/이용시간은 **이용건수 가중 평균**이 가능하도록 `거리합 = 이동거리 × 이용건수`, `시간합 = 이용시간 × 이용건수`로 저장합니다.
- `날짜`는 `2025-07-01`을 기준으로 한 `int16 day-offset`으로 저장합니다. parquet 용량과 rerun 메모리를 줄이기 위한 방식이며, 앱에서 화면용 날짜로 다시 변환합니다.
- 이동거리 ≤ 100km, 이용시간 ≤ 1,440분으로 이상치를 제한했습니다.
- `borrow.xlsx`는 상단 4줄이 헤더라 `skiprows=4`로 읽습니다. 번호/자치구/위도/경도와 LCD·QR 거치대수를 추려 대여소별 집계와 조인합니다. 원본 이용 데이터에는 실시간 자전거 수가 없어, 상세 화면의 '평균 거치대수'는 마스터의 거치대수(자전거 수용 대수)를 사용합니다.
- 지도는 `seoul_districts.geojson`(25개 자치구, WGS84)을 Plotly `Choropleth`로 그리고, 대여소 마스터의 자치구와 조인해 구별 이용량을 채색합니다. `fitbounds`로 서울 전체를 화면에 맞추고 모드바·휠 확대·더블클릭 확대·드래그를 비활성화했습니다. 마우스 오버 시 구 이름·이용건수·대여소 수·평균 이용시간이 표시됩니다.
- 대여소 좌표는 위도/경도(WGS84)가 경계 GeoJSON과 같은 좌표계이며, 실제 렌더링에서 강서구 대여소 196개 중 195개가 구 polygon 안에 들어오는 것을 확인했습니다(나머지 1개는 2013년 경계와 현재 대여소 위치 차이). 상세 지도에서 구 면이 보이지 않던 문제는 `featureidkey="properties.name"` 누락이 원인이었고 수정했습니다.
- 호버 줌(1.04배 확대 + 테두리 강조)은 **전체 지도에만** 적용됩니다. 상세 지도에는 적용하지 않습니다. Plotly 기본 툴팁(구 이름·이용건수·대여소 수·평균 이용시간)을 유지하기 위해 path의 `pointer-events`는 기본값(`none`)으로 두고, Plotly의 `plotly_hover`/`plotly_unhover` 이벤트로 `gu-hover` 클래스를 토글해 확대 효과를 냅니다. 클릭은 좌표 기반 polygon 판정(`isPointInFill`)으로 처리해 툴팁과 충돌하지 않습니다.
- 구역 클릭/전체 보기 전환 지연을 줄이기 위해, 필터 조건별 집계 결과(`compute_aggregates`)를 캐시하고 상세 테이블도 한 번만 만들어 재사용합니다. 원본 parquet는 파일별로 하나씩 읽어 집계한 뒤 즉시 해제하므로, 전체 2,470만 행을 동시에 메모리에 올리지 않습니다(로컬 측정 앱 프로세스 약 290MB).

## 데이터로 본 핵심 패턴 (2025.07~2026.06 전체, 365일)

| 항목 | 결과 |
|---|---|

| 평균 이동거리·시간 | 2.83km / 25.2분 (이용건수 가중) |
| 시간대 | 18시(362.8만건) > 17시(308.3만) > 8시(295.3만) > 19시 > 16시 — 출퇴근 쌍봉형 |

| 인기 대여소 | 마곡나루역 2번 출구, 롯데월드타워, 마곡나루역 3번 출구 등 |

## Community Cloud 배포

1. 이 폴더를 GitHub 저장소에 푸시합니다 (`app.py`와 같은 폴더에 parquet·xlsx·geojson이 함께 있어야 합니다). parquet는 **월별 12개**로 나눠 각 약 10~13MB이므로 파일당 25MB 제한을 만족합니다. (`prepare_data.py`는 이전 연도별 파일을 자동으로 정리합니다.)
2. https://share.streamlit.io 에서 저장소·브랜치·`app.py`를 지정합니다.
3. `requirements.txt`에 검증된 버전이 고정되어 자동 설치됩니다. `prepare_data.py`는 클라우드에서 실행할 필요가 없습니다.
4. `.gitignore`는 `__pycache__`와 로컬 시크릿만 제외합니다. parquet·xlsx·geojson은 앱 실행에 필요하므로 커밋에 포함해야 합니다.
